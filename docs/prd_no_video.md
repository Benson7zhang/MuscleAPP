# 健身助手 (MuscleFit) 产品需求文档

## 1. 项目概述

### 项目名称
健身助手 (MuscleFit)

### 项目类型
Android 健身运动应用

### 核心功能概述
一款专注于肌肉训练和健身知识的移动应用，通过交互式人体肌肉图引导用户进行针对性训练，提供专业的私教服务和活跃的健身社区交流平台，配备实用的健身计算器工具。

### 目标用户
- 健身初学者：需要明确的训练指导和动作规范
- 中级健身爱好者：寻求更丰富的训练动作和计划
- 高级健身者：需要专业私教指导
- 健身教练：展示专业能力、获取学员

## 2. 功能列表

### 2.1 交互式人体肌肉图
- 支持男性/女性两个人体模型
- 正面和背面视图切换
- 点击任意肌肉部位显示对应的训练动作
- 肌肉高亮显示功能
- 肌肉解剖知识科普（肌肉名称、位置、功能）

### 2.2 动作库系统
- 按肌肉部位分类（胸部、背部、肩部、手臂、腹部、腿部、臀部）
- 按训练方式筛选（徒手训练、哑铃训练、杠铃训练、弹力带训练、拉伸）
- 按难度级别筛选（入门级、进阶级、高手级）
- 动作详情页：动作说明、目标肌肉、辅助肌肉、动作要点、常见错误
- 动作图片和GIF演示支持

### 2.3 训练计划
- 根据用户身体数据和目标制定个性化计划
- 预设训练计划模板（减脂计划、增肌计划、塑形计划）
- 每日训练任务推送
- 训练历史记录查看

### 2.4 私教服务
- 教练个人主页：头像、简介、专长、资质证书展示
- 教练列表：按地区、专长筛选
- 私教预约：选择教练、预约时间、确定课程类型
- 课程类型：线下训练指导、线上视频指导、饮食计划定制
- 课程订单管理：购买课程、查看订单、评价教练

### 2.5 健身社区（小红书风格）
- 社区首页：双列瀑布流卡片式布局（小红书风格）
- 帖子形式（仿照小红书）：
  - 大封面图+标题+正文摘要
  - 多图轮播展示（1-9张图片）
  - 话题标签显示
  - 点赞、收藏、评论数量展示
  - 底部操作栏（点赞、收藏、评论、分享）
- 帖子类型：图文帖子、训练打卡
- 帖子功能：发布图文、点赞、评论、收藏、分享
- 话题标签：增肌、减脂、饮食、装备、康复等
- 个人主页展示：关注、粉丝、发布的帖子、获赞与收藏

### 2.6 健身计算器
- 卡路里计算器：根据活动类型和时长计算消耗
- 宏量营养素计算器：计算蛋白质、碳水、脂肪摄入量
- 1RM极限重量计算器：计算单次最大举重重量
- 体脂率计算器：根据身高体重腰围估算

### 2.7 健身知识库
- 肌肉解剖学知识
- 营养饮食建议
- 训练技巧和注意事项
- 健身术语解释

### 2.8 用户个人中心
- 用户身体数据管理（身高、体重、目标）
- 训练记录统计
- 收藏夹功能（收藏动作、帖子、教练）
- 订单记录（购买的私教课程）
- 设置（单位制、语言、主题、通知）

## 3. 用户交互流程

### 3.1 主流程：选择肌肉并开始训练

```
用户打开APP
    ↓
进入首页（显示人体肌肉图）
    ↓
点击目标肌肉部位（如：胸部）
    ↓
显示该部位的训练动作列表
    ↓
选择具体动作进入动作详情页
    ↓
查看动作说明和图片/GIF
    ↓
开始训练或收藏动作
```

### 3.2 私教预约流程

```
用户进入私教页面
    ↓
浏览教练列表或搜索特定教练
    ↓
查看教练主页和详情
    ↓
选择课程类型和预约时间
    ↓
确认订单并支付
    ↓
完成预约，等待教练确认
```

### 3.3 社区互动流程（小红书风格）

```
用户进入社区页面
    ↓
浏览双列瀑布流帖子（小红书风格）
    ↓
点击帖子进入详情页
    ↓
查看大图轮播、点赞、收藏、评论
    ↓
发布图文帖子或训练打卡
    ↓
关注其他健身爱好者
```

### 3.4 计算器使用流程

```
用户进入计算器页面
    ↓
选择计算器类型（卡路里/宏量/1RM）
    ↓
输入相关参数
    ↓
获取计算结果
    ↓
查看详细解释和建议
```

## 4. UI/UX 设计方向

### 整体视觉风格
- 现代简洁的健身应用风格
- 采用深色主题为主（适合健身房环境使用）
- 强调专业性和科技感
- 使用绿色/蓝色作为主色调，体现健康和活力

### 配色方案
- 主色：深绿色 (#10B981) - 代表健康和活力
- 辅助色：天蓝色 (#3B82F6) - 代表科技和专业
- 背景色：深灰色 (#1F2937) - 护眼适合运动场景
- 文字色：白色/浅灰色 (#FFFFFF / #9CA3AF)
- 强调色：橙色 (#F59E0B) - 用于重要操作和提醒

### 布局设计
- 底部导航栏：首页、动作库、私教、社区、我的
- 首页：以人体肌肉图为核心，清晰直观
- 私教页面：教练卡片展示，预约流程引导
- 社区页面：双列瀑布流卡片式布局（小红书风格）
- 帖子卡片：大封面图+标题+话题标签+互动数据
- 卡片式布局展示内容，信息层次分明
- 大图标和按钮适合运动时操作

### 社区界面详细设计（小红书风格）
- **首页瀑布流**：双列布局，图片为主，标题为辅
- **帖子卡片**：
  - 顶部：用户头像+昵称+发布时间
  - 中部：大封面图（可多图轮播）+ 标题 + 正文摘要（最多显示3行）
  - 底部：话题标签 + 点赞/收藏/评论数量
  - 操作栏：点赞图标、收藏图标、评论图标、分享图标
- **图片展示**：支持1-9张图片轮播，点击可全屏浏览
- **详情页**：大图展示、完整正文、评论列表、相关推荐

### 交互设计
- 人体肌肉图支持点击和滑动操作
- 动作图片支持缩放预览
- 社区帖子支持图片轮播、点赞、收藏
- 计算器支持实时计算和结果对比
- 训练计划支持进度追踪和完成确认
- 私教预约支持日历选择和时间段筛选

## 5. 技术实现要点

### 5.1 数据结构
- 肌肉部位数据：部位名称、位置坐标、关联动作列表
- 动作数据：动作名称、分类、难度、详细说明、图片/GIF链接、动作要点
- 教练数据：个人信息、资质证书、可用时段、课程价格、用户评价
- 帖子数据：标题、内容、图片列表（1-9张）、话题标签、点赞数、收藏数、评论数、发布时间、作者信息
- 用户数据：个人信息、训练记录、收藏数据、订单数据

### 5.2 离线支持
- 核心动作库支持离线查看
- 用户数据本地存储
- 训练计划离线可用
- 帖子缓存支持离线浏览

### 5.3 性能要求
- 页面加载时间 < 2秒
- 图片加载和浏览流畅
- 人体肌肉图交互响应灵敏
- 瀑布流布局流畅滚动

### 5.4 消息通知
- 私教课程提醒
- 社区互动通知（点赞、评论、关注）
- 训练任务推送

## 8. 版本对比分析（不带视频版 vs 带视频版）

### 不带视频版本优势
- 开发成本更低：无需视频处理、存储、转码
- 节省存储空间：用户端存储需求小
- 加载速度更快：图片加载比视频快
- 服务器成本低：无视频带宽和存储费用
- 适合初创阶段：MVP快速上线验证

### 不带视频版本劣势
- 动作演示不够直观：图片/GIF无法完全展示动作细节
- 用户体验较差：无法观看动作视频教学
- 竞争力较弱：市场上竞品多有视频功能
- 社区内容单一：无视频帖子类型

### 建议
- 第一阶段：先开发不带视频版本，快速上线验证
- 第二阶段：根据用户反馈和数据，再决定是否添加视频功能
